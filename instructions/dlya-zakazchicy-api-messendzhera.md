# Инструкция для заказчицы: открыть API мессенджера Авито

Ключи у вас уже есть, **новое приложение создавать не нужно**.
Нужно только оплатить подписку, в которой есть пункт **«API мессенджера»**.

По вашим объявлениям видно: они в разделе **«Ремонт и строительство»**
(Самара, «Окна по цене завода», «Пластиковые окна ПВХ по цене завода»).
Это **товары**, не услуги. Для товаров Авито открывает чаты через API
только на подписке **«Максимальная»**. **«Расширенной» мало** — карточка
«API мессенджера» там может висеть в списке, но тексты чатов всё равно закрыты.

---

## Шаг 0. Войдите в нужный кабинет

1. Откройте [avito.ru](https://www.avito.ru).
2. Войдите в аккаунт, **где висят объявления про окна** (профиль вроде «ГК Добрые»).
3. Слева в меню должны быть пункты:
   **«Профессиональный план»**, **«Аналитика»**, **«Профиль и настройки»**, кошелёк.
4. Если слева «Избранное», «Резюме», «Гараж», а под именем написано **«Частное лицо»** —
   вы не в том кабинете. Выйдите и зайдите в бизнес-аккаунт с объявлениями.

---

## Шаг 1. Откройте профессиональный план

**Вариант А (из меню)**  
Слева нажмите **«Профессиональный план»**.

**Вариант Б (прямая ссылка)**  
Откройте: [avito.ru/profile/extended](https://www.avito.ru/profile/extended)

Сверху будут вкладки тарифов, например:

- Расширенная
- **Максимальная** ← нужна эта
- Ультра

Нажмите **«Максимальная»**.

---

## Шаг 2. Проверьте, что в тарифе есть мессенджер

Перейдите на вкладку **«Автоматизация»** (в ряду: Все / Поддержка / Аналитика / Автоматизация / Профиль / Продажи).

В списке должна быть карточка:

**API мессенджера**  
«Работайте с чатами из Авито в своей CRM-системе»

- На саму карточку **нажимать не обязательно** — это справка, не кнопка включения.
- Если карточки нет на Максимальной — напишите нам, пришлите скрин этой вкладки.

---

## Шаг 3. Подключите и оплатите Максимальную

1. На экране Максимальной найдите кнопку вроде **«Подключить»** / **«Перейти»** / **«Оплатить»**.
2. Авито покажет сумму **за ваш кабинет** (она своя: категория, регион, пакет объявлений).
3. Пополните **кошелёк** на **полную** сумму. Если не хватает даже 100–200 ₽, доступ к чатам могут не открыть.
4. Дождитесь, пока статус станет «подписка подключена», без фразы «не хватает … ₽».

**Базовую** не берите.  
**Расширенную** для окон в «Ремонт и строительство» не хватает.  
Тариф **«оплата за сделки»** (Авито Доставка) сюда не подходит — нужен тариф **за просмотры**.

---

## Шаг 4. Ключи не трогайте

Раздел **Профиль и настройки → Интеграции и API** уже настроен.
Client ID и Client Secret нам не перевыпускайте, если их не потеряли.
Secret показывают один раз — если перевыпустить, старые ключи умрут.

---

## Шаг 5. Напишите нам

После оплаты напишите: «подписка Максимальная оплачена».
Мы проверяем доступ: если Авито отдаёт тексты сообщений — бот можно включать.
Если снова ошибка про подписку — пришлите скрин вкладки «Автоматизация» на Максимальной
и строку про списание с кошелька.
